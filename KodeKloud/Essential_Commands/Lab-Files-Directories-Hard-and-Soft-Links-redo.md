# Lab - Files, Directories, Hard and Soft Links ## Task: What is the top-level directory in Linux? ## Solution: The root directory is /. This is the top-level directory. There can be no other directories above it. ## Task: In what form does Linux organise files and directories? ## Solution: Linux organizes files and directories in a filesystem tree. ## Task: What is the command to print your current working directory? ## Solution: #### pwd ## Task: What is the command to climb up one directory? ## Solution: #### cd .. is the command to climb up one directory. ## Task: Absolute paths always start out with the root directory /. Then we specify the sub-directories we want to descend into; /home/bob/Documents/Invoice.pdf is an example of such a path. In this case, first home, then bob, and then Documents. We can see the sub-directory names are separated by a /, and we finally get to the file we want to access, i.e, Invoice.pdf. An absolute path can end with the name of a file or a directory. As per the example above, If we'd want to delete the Documents directory, how would we specify the path? ## Solution: If we'd want to delete the Documents directory, we'd specify the path like: /home/bob/Documents ## Task: Create a directory named lfcs under the /home/bob directory. ## Solution: Run the below command: #### mkdir /home/bob/lfcs ## Task: Create a blank file named lfcs.txt under the/home/bob/lfcs directory. Is the "/home/bob/lfcs/lfcs.txt" file created? ## Solution: Run the below command: #### touch /home/bob/lfcs/lfcs.txt ## Task: Copy the /tmp/Invoice directory (including all its contents) to the /home/bob directory. Is the "/tmp/Invoice" directory copied to the "/home/bob" directory? ## Solution: Run the below command: #### cp -r /tmp/Invoice /home/bob/ ## Task: Copy the /home/bob/myfile.txt file to the/home/bob/data/ directory. Make sure to preserve its attributes. Is the file copied with all attributes? ## Solution: #### cp -a /home/bob/myfile.txt /home/bob/data/ ## Task: Copy the /home/bob/lfcs directory (including all its content) into the /home/bob/old-data/ directory. Is the "/home/bob/lfcs" directory copied into the "/home/bob/old-data/" directory? ## Solution: Execute the below command: #### cp -r /home/bob/lfcs /home/bob/old-data/ ## Task: Delete the /home/bob/lfcs/lfcs.txt file. Is the "/home/bob/lfcs/lfcs.txt" file deleted? ## Solution: Execute the below command: #### rm /home/bob/lfcs/lfcs.txt ## Task: Move all contents, excluding the directory itself, from /home/bob/lfcs to /home/bob/new-data/ directory. Are the contents of the "/home/bob/lfcs" directory moved to the "/home/bob/new-data/" directory? ## Solution: Execute the below command: #### mv /home/bob/lfcs/* /home/bob/new-data/ ## Task: Delete directory /home/bob/lfcs . Is the "/home/bob/lfcs" directory deleted? ## Solution: Run the below command: #### rm -rf /home/bob/lfcs ## Task: Create a soft link to /tmp directory. Create this link in /home/bob directory and call it link_to_tmp. Is the "link_to_tmp" softlink created? ## Solution: Run the below command: #### ln -s /tmp /home/bob/link_to_tmp ## Task: Create a hard link to /opt/hlink file. Create this link in /home/bob/ directory and call it hlink. Has the required hard link been created? ## Solution: Execute the below command: #### ln /opt/hlink /home/bob/hlink ## Task: There is a file called /home/bob/new_file; rename this to /home/bob/old_file. Is "/home/bob/new_file" renamed to "/home/bob/old_file"? ## Solution: Run the below command: #### mv /home/bob/new_file /home/bob/old_file ## Task: Create a directory named 9 under the /tmp/1/2/3/4/5/6/7/8 directory. Please note that the structure of sub-directories from 1 to 8 does not exist. However, mkdir has a command line option to automatically create all of these sub-directories automatically in one shot, instead of 9 consecutive commands. This option is described in the help output or manual pages as make parent directories as needed. Find out what the correct option is and use it to create the directory in one shot. Is the "/tmp/1/2/3/4/5/6/7/8/9" directory created? ## Solution: Run the below command: #### mkdir -p /tmp/1/2/3/4/5/6/7/8/9 ## Task: ls -l shows you the time when a file has been last modified, but it only shows you the hour and the minute, usually in a form like 17:53. Find another way to make ls display the full/exact last modified time for the files in /home/bob directory. At what exact time was important_file created/modified? ## Solution: Run the below command: #### ls --full-time

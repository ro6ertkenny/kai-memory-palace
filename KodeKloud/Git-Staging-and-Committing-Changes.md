# Git - Staging-and-Committing-Changes

3 Steps to Modifying Code and Tracking Changes with Git:

- Making changes in the working area (the project directory we're currently in)

- Adding the changes we want to track with Git to the staging area (how we tell Git about the changes that we've made to our project or what changes we want it to track in the next commit)

- Committing our changes

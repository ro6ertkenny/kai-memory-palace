## 🧪 How To Use (Normal Training Mode)

1) Start a timer  
2) Run the playbook **exactly as written**  
3) Run the verification commands  
4) If verification fails:
   - reset immediately
   - repeat immediately  

Rule:

> If you fix it without resetting, **you cheated yourself**.

# 🧭 Troubleshooting — Master Index

This index is the entry point for **Linux-wide troubleshooting discipline**.

This directory is for:
- repeatable failure patterns
- operational mistakes worth preventing
- short recovery rules that apply everywhere

Domain-specific troubleshooting lives in its wing (example: networking playbooks in `linux/networking/troubleshooting/`).

---

## 🧠 Core Mental Model

Inspect → Hypothesize → Act → Verify → Document

If you skip inspection, you lose evidence and misdiagnose.

## 🧱 Contribution Rule

Only add content if it:
- actually happened
- cost real time
- is likely to recur

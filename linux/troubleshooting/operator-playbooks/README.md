# 🧰 Operator Playbooks — README

## 🎯 Purpose
This directory is a **hands-on incident playbook bank**.

It trains one thing:

**Symptom → Evidence → Decision → Action → Verification**

Not “run random commands.”

---

## 🧠 Mental Mode
**Operating a Linux system under uncertainty**

You should be able to:
- triage quickly without panic
- collect the right evidence
- make a decision that matches the evidence
- take the smallest safe action
- verify outcomes

---

## 📁 Structure
This directory is divided into two tiers:

### ✅ `core/`
Daily drills.

These are the **highest-frequency failure patterns** you should be able to run
without hesitation.

Core is intentionally capped and refined over time.

### 🧠 `advanced/`
Reference scenarios.

These are **rarer, more specialized, or more environment-specific** incidents.
They are not daily drills unless you are actively preparing for them.

---

## 🔁 How to Use This Wing
1) Start with `core/triage-playbook.md`
2) Drill one scenario at a time
3) Speak the decision out loud:
   - what you saw
   - what it means
   - what you will do
   - how you will verify

---

## 🧭 Operator Rule Zero
**Symptoms first. Evidence second. Action last. Verification always.**

# 🧪 LFCS Practice Questions

## 🎯 Purpose
This wing is for **active recall** and **operator drills**.

These are not notes.
They are scenarios you should be able to reason through under pressure.

Use them to practice:

- symptom recognition
- triage sequencing
- evidence gathering
- safe decision-making
- verification discipline

---

## 🧠 Mental Mode
**Exam operator**

You are training the skill:

Symptom -> Evidence -> Decision -> Action -> Verification

---

## 🧭 How To Use

For each scenario:

1) Read the symptom.
2) Speak your plan out loud.
3) Run only the first triage step.
4) Interpret the output.
5) Decide what you do next and why.
6) Verify the result.

Do not skip interpretation.

---

## ✅ Scenarios

- `scenario-a-system-feels-slow.md`
- `scenario-b-disk-is-full.md`
- `scenario-c-service-is-down.md`
- `scenario-d-process-wont-die.md`
- `scenario-e-cpu-pegged.md`

---

## 🏁 Graduation Standard

You can complete each scenario without hesitation:

- you choose the correct first commands
- you can explain what the outputs mean
- you take the minimum safe action
- you verify the system state afterward
